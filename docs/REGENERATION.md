# Sprite regeneration list (for ChatGPT)

Five animation sheets need to be redone. The OpenAI API credits ran out, so these are meant to be generated by hand in ChatGPT's image generator and dropped back into the project.

## How to do each one

1. Start a **new chat** for each sheet (keeps the character from drifting).
2. Attach the character's reference sheet:
   - Bhadran: `Bhadran_ Kalaripayattu Warrior Reference Sheet.png`
   - Rudrani: `Rudrani_ Silambam Warrior Reference Sheet.png`
3. Paste the prompt below. Ask for a **landscape 3:2 image (1536x1024)**. If ChatGPT gives a different size that is fine, but keep it landscape.
4. Check the result before saving:
   - correct number of frames, in one row (or two rows if it insists - the pipeline handles both)
   - the **same character** as the reference (face, hair, costume colours, the red waist sash for Bhadran, the braid and jasmine flowers for Rudrani)
   - flat bright green background (it does not need to be perfectly uniform; the pipeline removes gradients and shadows)
   - **nothing touching or cut by the image edge**
   - each frame clearly different in pose, as described
5. Save the image as a PNG with the exact filename given, into the folder given.
6. Tell me when they are in - I will run the processing, copy them into `public/sprites/`, and check them in-game.

## Notes

- If ChatGPT draws more frames than requested, that is OK for walk-type sheets, but for these five please keep it to the exact count so the right frames are used.
- Keep the camera side-on and the character facing **right** in every frame.
